# Manuscript: Uncertainty-aware MPC as a self-adjusting safety margin

Applied Energy manuscript in the Elsevier CAS double-column template (`cas-dc`).

## Files

- `manuscript.tex` – the text. It contains no hand-typed results: every number is a macro from `numbers.tex`,
  every data table is a file in `tables/`.
- `numbers.tex`, `tables/*.tex` – generated by `scripts/make_numbers.py` from the repository and `results/paper`.
- `figures/` – `fig1`–`fig4` from `results/paper/scripts/figures.py` (copied), `fig5_hard_day` from
  `scripts/fig_day.py`, `fig6_variability_capacity` from `scripts/fig_var_cap.py`. The method diagram is TikZ inside `manuscript.tex`.
- `refs.bib` – bibliography (124 entries, 123 cited), generated by `literature/build_lit.py` of the study repository;
  `REFERENCES_CHECK.md` and the `verified` column of `literature/literature.csv` say what still has to be verified.
- `cas-dc.cls`, `cas-common.sty`, `cas-model2-names.bst`, `thumbnails/` – Elsevier template files.

## Rebuild

From the code repository root (needs `results/paper`; in the study repository set `KAIROS_ROOT` and
`STUDY_RESULTS`, see its README):

```
python paper/manuscript/scripts/make_numbers.py
python results/paper/scripts/figures.py && cp results/paper/figures/fig[1-4]*.pdf paper/manuscript/figures/
python paper/manuscript/scripts/fig_day.py
python paper/manuscript/scripts/fig_var_cap.py   # needs variability/ and capacity_economics/
cd paper/manuscript && latexmk -pdf manuscript
```
