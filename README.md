# ua-mpc-safety-margin-study

Experiments, results, literature and manuscript of

> J. Szeles, L. Deszát: *Uncertainty-aware MPC as a self-adjusting safety margin for renewable-powered production
> cells* (manuscript in preparation for Applied Energy). Department of System Engineering, University of Pannonia.

The controller code (Kairos) lives in [szelesj-lab/uncertainty-aware-mpc](https://github.com/szelesj-lab/uncertainty-aware-mpc).
This repository holds everything needed to re-run, check and write up the study on top of it.

## Questions

1. Does an uncertainty-aware (UA) MPC, tuned with the same budget, keep the SoC band better than a deterministic MPC
   and than a deterministic MPC with a constant back-off, at the same cost?
2. When does the self-adjusting margin matter? The ratio **r_E** (95 % energy deficit until the next re-plan per usable
   capacity) predicts where a constant back-off tuned for one setting stops being enough.
3. Does the *variability* of the forecast uncertainty carry information, beyond its level?
4. Can a *small* battery, which earns the most per Wh but has the largest r_E, be operated safely without re-tuning?

## Main results (all numbers in `results/`, see `docs/JELENTES_2026-10-24.md`)

- Final test (44 days, run once after pre-registration): UA vs deterministic MPC: band violation 10.74 → 0.20 pp·h,
  BMS protection steps 108 → 49, at equal net cost (1.515 vs 1.517 €). UA vs a tuned constant back-off: equal
  (0.20 vs 0.15 pp·h, difference not significant).
- Decision map (development period, weights not re-tuned): where r_E ≤ 0.023 the back-off and UA tie; where
  r_E ≥ 0.047 the back-off violates 2.8–19.1 pp·h, UA 0.04–1.25 pp·h, at +0.1…+0.6 % cost.
- Variability: UA with σ held constant at its mean violates 2.3–3.8 times more than UA with the real time-varying σ
  in all four tested cells; doubling the variability of σ lowers the violation in three of them; costs within 0.11 %
  (`results/variability/`).
- Capacity: 36 Wh saves 71 % of what 144 Wh saves against grid-only operation; the first 36 Wh earn 7.2 m€/Wh, the
  last 72 Wh 0.65 m€/Wh (`results/capacity_economics/`).

## Layout

| Path | Content |
|---|---|
| `experiments/` | replay engine and stages (`engine.py`, `stages.py`), development fronts and ablations, capacity economics, figures, `run_all.sh` |
| `results/` | snapshot of every run: per-step series (`*/steps/*.csv`), solver logs, summaries, bootstrap tables, figures |
| `literature/` | 124-paper database (`literature.csv`, `references.bib`) and narrative review (`review.md`) |
| `manuscript/` | LaTeX source (Elsevier `cas-dc`); every number is generated by `manuscript/scripts/make_numbers.py` |
| `docs/` | experimental protocol, result report (Hungarian) |
| `patches/` | the code change needed on top of the code repository (resumable tuning, SoC recovery) |

## Re-running

```bash
git clone https://github.com/szelesj-lab/uncertainty-aware-mpc ../uncertainty-aware-mpc
cd ../uncertainty-aware-mpc     # a version with the four-period split (named_periods in src/replay.py)
git apply ../ua-mpc-safety-margin-study/patches/kairos-resume-and-soc-recovery.patch
# Python environment and data as described in that repository (ENTSO-E key in .env, never in code)
cd ../ua-mpc-safety-margin-study
KAIROS_ROOT=../uncertainty-aware-mpc experiments/run_all.sh     # many hours on 2 cores
cd manuscript && latexmk -pdf manuscript
```

Only the manuscript numbers and tables (no replay):

```bash
KAIROS_ROOT=../uncertainty-aware-mpc STUDY_RESULTS=$PWD/results python manuscript/scripts/make_numbers.py
```

`docs/protocol.md` gives the periods, the pre-registered selection rule, the metrics and the two deviations
(SoC recovery added after the final test; thread settings).
